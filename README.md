# Полка

Веб-приложение для сохранённого контента: вставляете ссылку на пост, статью или видео, либо просто записываете мысль, а Полка сама раскладывает это по трём папкам:

- **Учеба** — курсы, лекции, статьи, туториалы, конспекты;
- **Посты** — интересные посты из каналов и соцсетей, новости, мемы;
- **Идеи** — свои мысли, планы, задумки.

Работает в браузере на компьютере и телефоне, устанавливается на домашний экран и умеет принимать ссылки через «Поделиться» (Android).

## Возможности

- Автоматический выбор папки по сайту, ключевым словам и хэштегам `#учеба`, `#посты`, `#идеи`
- Необязательная классификация нейросетью (Claude API) — ключ указывается в настройках и хранится только в браузере
- Ссылки на Telegram-посты отображаются как `@канал · пост 123`
- Перенос записи в другую папку одним нажатием, удаление с возможностью отмены
- Поиск по записям
- Экспорт и импорт в JSON для переноса между устройствами
- Работает офлайн (PWA, service worker)
- Светлая и тёмная тема

## Как устроено

Проект без сборки и зависимостей — обычные HTML, CSS и JavaScript.

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | оформление, светлая и тёмная тема |
| `classify.js` | правила выбора папки и запрос к Claude API |
| `app.js` | хранение записей, отрисовка, поиск, экспорт/импорт, приём ссылок через «Поделиться» |
| `manifest.webmanifest` | установка на телефон и пункт в меню «Поделиться» |
| `sw.js` | офлайн-режим |
| `icons/` | иконки приложения |

Записи хранятся в `localStorage` браузера, на сервер ничего не отправляется (кроме текста записи в Claude API, если указан ключ).

### Как выбирается папка

1. Хэштег в тексте (`#идеи`) — сразу в эту папку.
2. Если указан ключ Claude API — папку выбирает модель.
3. Иначе — правила: учебные сайты (Stepik, Coursera, Хабр, Википедия, arXiv…) → Учеба; соцсети и Telegram → Посты; текст без ссылки → Идеи; плюс подсчёт ключевых слов («курс», «лекция», «а что если», «мем»…).

## Запуск

### На GitHub Pages

1. Загрузите файлы в репозиторий.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты приложение будет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

### Локально

```bash
python3 -m http.server 8000
```
и откройте http://localhost:8000.

## Установка на телефон

- **Android (Chrome):** откройте сайт → меню ⋮ → «Добавить на главный экран». После этого в Telegram и других приложениях в меню «Поделиться» появится «Полка».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“». Ссылки вставляются вручную.
