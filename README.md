# Полка

Веб-приложение для сохранённого контента: вставляете ссылку на пост, статью или видео — Полка сама открывает её, читает и раскладывает по трём папкам. Если не уверена, куда положить, — спрашивает и запоминает ответ для этого канала или сайта.

- **Учеба** — курсы, лекции, статьи, туториалы, конспекты;
- **Посты** — интересные посты из каналов и соцсетей, новости, мемы;
- **Идеи** — свои мысли, планы, задумки.

Работает в браузере на компьютере и телефоне, устанавливается на домашний экран и умеет принимать ссылки через «Поделиться» (Android).

## Возможности

- Чтение постов по ссылке: текст поста Telegram, заголовок и описание статьи или видео
- Несколько ссылок за раз — каждая с новой строки
- Автоматический выбор папки по тексту, сайту и хэштегам `#учеба`, `#посты`, `#идеи`
- Вопрос «Куда положить?», если уверенности нет, и память о решениях по каждому каналу и сайту
- Необязательная классификация нейросетью (Claude API) — ключ указывается в настройках и хранится только в браузере
- Ссылки на Telegram-посты отображаются как `@канал · пост 123`
- Перенос записи в другую папку одним нажатием, удаление с возможностью отмены
- Поиск по записям
- Экспорт и импорт в JSON для переноса между устройствами
- Работает офлайн (PWA, service worker)
- Светлая и тёмная тема

## Как устроено

Проект без сборки и зависимостей — обычные HTML, CSS и JavaScript.

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | оформление, светлая и тёмная тема |
| `classify.js` | правила выбора папки, оценка уверенности, запрос к Claude API |
| `reader.js` | чтение страницы по ссылке |
| `api/read.js` | собственная читалка страниц (серверная функция для Vercel) |
| `app.js` | хранение записей, отрисовка, поиск, экспорт/импорт, приём ссылок через «Поделиться» |
| `manifest.webmanifest` | установка на телефон и пункт в меню «Поделиться» |
| `sw.js` | офлайн-режим |
| `icons/` | иконки приложения |

Записи хранятся в `localStorage` браузера.

### Как читаются ссылки

Браузер не может напрямую скачать чужую страницу (ограничение CORS), поэтому Полка обращается к «читалке»:

1. Своя читалка `api/read.js` — работает, если сайт размещён на Vercel.
2. Если её нет (например, на GitHub Pages) — бесплатные публичные сервисы allorigins.win и codetabs.com.

Для Telegram читается публичная страница поста `t.me/канал/номер`: название канала и текст поста. Посты из приватных каналов прочитать нельзя — по ним Полка спросит.

### Как выбирается папка

1. Хэштег в тексте (`#идеи`) — сразу в эту папку.
2. Прошлые решения пользователя для этого канала или сайта.
3. Если указан ключ Claude API — папку выбирает модель.
4. Иначе — правила: учебные сайты (Stepik, Coursera, Хабр, Википедия, arXiv…) → Учеба; текст без ссылки → Идеи; плюс ключевые слова в тексте поста («курс», «конспект», «разбор», «мем», «новость», «а что если»…).

Если одна папка не опережает остальные с запасом, запись попадает в блок «Нужно решить». После ответа Полка запоминает выбор для источника и сама раскладывает остальные нерешённые записи из него.

## Запуск

### На GitHub Pages

1. Загрузите файлы в репозиторий.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты приложение будет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

### На Vercel (надёжное чтение ссылок)

1. Зайдите на vercel.com через аккаунт GitHub.
2. **Add New → Project → Import** репозиторий → **Deploy**, настройки менять не нужно.
3. Сайт появится по адресу вида `https://polka-….vercel.app` и будет обновляться сам при каждом изменении в репозитории.

### Локально

```bash
python3 -m http.server 8000
```
и откройте http://localhost:8000.

## Установка на телефон

- **Android (Chrome):** откройте сайт → меню ⋮ → «Добавить на главный экран». После этого в Telegram и других приложениях в меню «Поделиться» появится «Полка».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“». Ссылки вставляются вручную.
